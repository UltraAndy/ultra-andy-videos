## Cómo subir a Vercel (2 minutos)

### Opción 1: Más fácil (sin Git)

1. Ve a https://vercel.com
2. Click en **"Add New"** → **"Project"**
3. Click en **"Deploy with folder"** o **"Drag and drop project folder"**
4. **Arrastra esta carpeta `ultra-andy-videos/`** a Vercel
5. Click en **"Deploy"**

¡LISTO! Vercel te da un link como: `https://ultra-andy-videos.vercel.app`

### Opción 2: Con GitHub (más profesional)

1. Crea cuenta en https://github.com
2. Crea un nuevo repositorio llamado `ultra-andy-videos`
3. Sube esta carpeta a GitHub
4. Ve a https://vercel.com y conecta tu GitHub
5. Selecciona el repositorio
6. Click **"Deploy"**
